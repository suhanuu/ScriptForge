# ScriptForge 示例测试小说

开发阶段用这份小说测试分章、转换、润色功能。录演示视频也可以用。全文约 5000 字，3 章，涵盖对话、动作、场景切换，适合验证 LLM 输出质量。

---

## 第一章

# 第一章 深夜来客

林远的闹钟响了两遍，他翻了个身，把枕头压在头上。闹钟响了第三遍，他终于从被窝里伸出一只手，在床头柜上摸索着手机。

"关掉。"他哑着嗓子说。

手机没理他。闹钟继续响。

林远骂了一句脏话，抓起手机，眯着眼看了下时间——凌晨两点。

不是闹钟。是电话。

屏幕上跳动的名字让他瞬间清醒：**周明，技术总监**。

"喂？"林远接起电话，声音还带着睡意。

"小林，出事了。"周明的声音很低，像是在某个不能大声说话的地方。"生产环境的数据被人动了，订单表少了三千条记录。我刚从派出所出来，他们要看完整的操作日志。"

林远坐起来，脚踩到地上的薯片袋子。"什么意思？动了什么数据？"

"六小时前，有人用 root 权限直接连进了 PostgreSQL，执行了 delete 操作。没有走应用层，绕过了所有审计。你要查的是——"

"谁有 root 密码？"林远打断他。

"这就是问题所在。整个公司只有我和你知道 root 密码。"

电话那头沉默了几秒。林远能听到周明沉重的呼吸声，还有远处警笛的声音。

"你先别想太多，"林远说，一边从床上爬起来，打开笔记本电脑，"我去公司。你把服务器 IP 和登录凭证发我，路上先看看日志。"

"我已经在公司了。办公室只有我一个人。灯都是黑的。"

"那就开着灯。我二十分钟到。"

林远挂掉电话，抓了件外套就往外走。电梯里，他看着镜子里头发乱成一团的自己，脑子里已经开始跑排查逻辑——谁在凌晨两点用 root 删了三千条订单？为了什么？如果是周明干的，他为什么要报警？

雨打在出租车的挡风玻璃上。司机开着深夜电台，某个不知名的 DJ 正在放一首老歌。林远打开笔记本，连上手机热点，开始翻服务器的登录记录。

凌晨一点四十七分。root 账户登录。

来源于内网 IP：192.168.1.105。

林远的心跳漏了一拍。那是他自己的工位。

## 第二章

# 第二章 内网幽灵

二十分钟后，林远推开办公室的玻璃门。灯只开了半排，整个技术部像一座昏暗的洞穴，只有周明的工位亮着一盏台灯。

周明坐在电脑前，双手交叉抱在胸前，屏幕的光把他的脸照得惨白。

"你看这个。"周明把屏幕转向林远。

登录日志一条条列在终端里。林远看到了自己的 IP、自己的用户名、自己的时间戳。但那个时间点，他正在家里睡觉。

"我没来过。"林远说。

"我知道。"周明说，语气平静得反常。"你不觉得奇怪吗？正好在你睡觉的时候，正好用你的 IP，正好删了订单表里最关键的三千条记录——全是还没发货的高价值订单。"

"有人想栽赃？"

"不是栽赃。"周明站起来，走到窗边，背对着林远。"是测试。"

"什么？"

"三个月前，公司招了一个安全顾问，叫陈墨。你见过他。他说要做一个内部渗透测试，模拟内部人员恶意操作。老板批准的。只有我和老板知道。"周明转过身，"但我没让他删真实数据。"

林远沉默了。雨敲在窗户上，发出沉闷的声响。

"所以现在是什么情况？"林远问。"一个安全顾问拿到了 root 密码，做了他所谓的渗透测试，然后不小心删了真实数据？"

"他删的是真实数据，但不是不小心的。"

"你怎么知道？"

"因为我刚才去找他，他已经不在工位上了。他的抽屉清空了，工牌留在桌上。电话关机。"

林远坐到自己工位上，手指在键盘上快速地敲。他连上服务器，开始追踪陈墨的操作轨迹。不只是今晚的 delete——他往前面翻。

三天前，陈墨执行了一次异常的数据库导出。两天前，他新建了一个隐藏账户。昨晚八点，他修改了备份策略的保留天数，从三十天改成了三天。

"他在清理痕迹。"林远说。"一步一步来的。这不是临时起意。"

周明走过来，看着屏幕上的操作记录，脸色越来越沉。"三千条订单，每一条对应一个真实用户。他怎么拿走数据？"

"查一下他最近一个月的网络流量。"林远说。"如果他往外传了东西，防火墙应该有记录。"

周明回到自己电脑上开始查。林远继续往前翻日志，翻到一个月前，他停住了。

"周哥，你来看这个。"

周明走过来。屏幕上是一条数据库操作记录，日期是四周前。操作内容不是删数据，而是改数据——把订单表中的收件地址，修改了几百条。

所有被修改的地址，指向同一个小区。

林远放大那个地址，在搜索引擎里敲下小区名字。搜索结果第一条：三个月前，有人在该小区以远低于市场价的价格购买了一套房产。

房主名字：陈墨。

"他不是安全顾问。"周明说，声音里有一丝颤抖。"他是个内鬼。"

## 第三章

# 第三章 追踪

天快亮了。办公室里的灯全开了，两个程序员坐在会议室里，桌上摊着笔记本、咖啡杯和打印出来的操作日志。

"他的每一步都走得很干净。"林远指着日志说。"删除、备份、导出，全是合法操作。如果我不是从一个月前开始查，根本看不出来他在干什么。"

"可他犯了一个错误。"周明说。"他太贪了。"

"对。三周前那几百条地址修改，太集中了。如果只是改地址不买房，没人会发现。但房子一买，地址和人的关联就永远留在不动产系统里了。"

"我已经联系律师了。"周明说。"公司法务说，数据篡改可以追究刑责。但需要完整证据链。"

林远把屏幕转过来，上面是一个时间线图表。"我已经整理好了。从他入职到现在，每一次操作、每一条受影响的数据，全部标出来了。包括他导出数据后生成的本地文件时间戳——他可能不知道，PostgreSQL 会在系统日志里记录每一条 pg_dump 的执行时间和客户端地址。"

"那就是铁证。"

"还不够铁。"林远摇头。"他没有删干净。可能太自信了，也可能时间不够。他在退出前只清掉了最近三天的访问日志，但一个月前那几次操作记录还在归档里。"

林远打开一个隐藏目录，里面是一批扩展名为 .gz 的压缩文件。"PostgreSQL 的日志归档。默认保留三个月。他改备份策略的时候，只改了数据库备份，忘了这个。"

周明看着那些文件，脸上终于有了一丝笑意。"所以他以为已经把证据销毁了。"

"对。他以为只要删掉三天的日志，我们只能看到今晚的 delete 操作，而今晚的操作用的是我的 IP，所以看起来像是我干的。然后他会等风头过去，再通过那套房产把钱套出来。"

"但他没算到归档日志。"

窗外的天已经变成了深蓝色。远处有环卫工人开始扫街，扫帚在水泥地上发出沙沙的声响。

"还有一件事。"林远说，声音压低了些。"你刚才说，只有你和老板知道渗透测试的事，对吧？"

周明点头。

"那陈墨是怎么拿到 root 密码的？"

周明愣住了。他打开手机上的人力系统，查了陈墨的入职档案。

推荐人一栏，写着：**李建国——CEO**。

两人对视了一眼，谁都没有说话。雨终于停了，清晨的阳光从会议室的百叶窗缝隙中透进来，在墙上投下一道道细长的光影。

桌上林远的手机亮了。一条短信，陌生号码：

"林远是吧？别查了。有人要我带个话——你当什么都没看见，这件事就过去了。继续查，你家地址我也知道。"

林远把手机给周明看。周明看完，把手机轻轻放在桌上。

"报警吧。"他说。

林远点点头，但眼睛还盯着那条短信的发送号码。他在电脑上查了一下——号码的归属地，正是那个小区。

陈墨可能根本没走远。

---

> **说明：** 这份示例小说的对话比例高、情节推进快、场景变化清晰（公寓→出租车→办公室→会议室），适合验证 ScriptForge 的转换质量。三章分别测试：日常对话+内心独白（第一章）、技术排查+悬念推进（第二章）、多人对话+剧情收束（第三章）。
